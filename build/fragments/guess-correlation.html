Try this first

Play ten rounds of Linear only and watch the mean miss for the last ten rounds; the aim is to get it below 0.10. A common early error is to underestimate strong correlations: a cloud that looks loose can still have r = 0.8.

Then this

Change the points from 40 to 15. With few points, a cloud with r = 0.5 can look like almost anything. Then try 100.

And the catch

Switch on Include non-linear and clusters. Some plots now show a strong curved pattern with r near 0, or two clusters with a high r and no pattern inside either cluster. r measures only the strength and direction of linear association, so always look at the plot before you trust the number.
